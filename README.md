# 2025 浙江省网络安全大赛 · 初赛 Web Writeup

本仓库收录了 **2025 年浙江省网络安全大赛初赛 Web 方向** 的个人解题 Writeup（WP），记录了每道题目的完整思路、实操步骤与踩坑过程，并整理了相关知识点和方法论，方便自己复盘，也希望能帮助到正在学习网络安全的同学。

## 题目一览

| 题目 | 类型 | 核心考点 |
|---|---|---|
| **Upload1** | 文件上传 | 黑名单绕过、`<?=` 短标签、WebShell 上传与执行 |
| **EzSerialize** | PHP 反序列化 | 序列化构造、魔术方法（`__toString`、`__call`） |
| **UploadKing** | 文件上传 + XXE | SVG 上传、XXE 外部实体读取文件 |

## 文档简介

### Upload1（文件上传漏洞）

完整还原了从“正常上传”到“发现并利用漏洞”的全过程：

1. 先正常上传 png 文件，熟悉业务流程；
2. 通过测试文件分别判断前端与后端的检测力度；
3. 利用后缀名大写绕过后端黑名单；
4. 测试 MIME 类型、GIF89a 魔术头、文件内容长度等检测点；
5. 分析后端对 PHP 起始标记的检测逻辑，使用 `<?=` 短标签绕过危险内容扫描；
6. 上传 WebShell 并根据回显判断代码是否被解析、执行；
7. 在 Windows 环境下通过命令执行查找目录，最终读取 flag。

### EzSerialize（PHP 反序列化）

通过构造 `User -> Admin -> FileReader` 的对象链，使用 `serialize()` 序列化并 Base64 编码，理解反序列化题目的基本构造方式，以及 `__toString()`、`__call()` 等魔术方法的触发时机。

### UploadKing（SVG 上传 + XXE）

1. 排查发现白名单内只有 SVG 是纯文本（本质是 XML），确定 XXE 方向；
2. 上传正常 SVG，确认内容进入 XML 解析器；
3. 验证实体替换开关 `LIBXML_NOENT` 已开启；
4. 利用外部实体（`LIBXML_DTDLOAD`）读取系统文件，最终读取 flag。

## 涵盖知识点

- 如何通过“是否发出新请求”判断前端与后端检测；
- 后缀名黑名单 / 白名单、大小写绕过、MIME 类型与 GIF89a 魔术头；
- `<?=` 短标签与 `<?php` 标签的区别，以及后端危险内容扫描的触发逻辑；
- PHP 代码利用三步：**上传 → 解析 → 执行**；
- 根据页面回显与源码判断代码“未被解析 / 被解析但未执行 / 已执行”；
- PHP 反序列化对象构造与 `__toString()`、`__call()` 魔术方法；
- XXE 利用条件：`LIBXML_NOENT`、`LIBXML_DTDLOAD`、`file://` 协议；
- Windows 下常用命令执行、文件读取（win.ini 验证、highlight_file 等）。
