# 2025 浙江省网络安全大赛 · 初赛 Writeup

本仓库收录了 **2025 年浙江省网络安全大赛初赛** 的个人解题 Writeup（WP），记录了每道题目的完整思路、实操步骤与踩坑过程，并在文末整理了相关知识点和方法论，方便自己复盘，也希望能帮助到正在学习网络安全的同学。

## 文档简介

当前收录的题目为 **Upload1（文件上传漏洞）**，WP 完整还原了从"正常上传"到"发现并利用漏洞"的全过程：

1. 先正常上传 png 文件，熟悉业务流程；
2. 通过测试文件分别判断前端与后端的检测力度；
3. 利用后缀名大写绕过后端黑名单；
4. 测试 MIME 类型、GIF89a 魔术头、文件内容长度等检测点；
5. 分析后端对 PHP 起始标记的检测逻辑，使用 `<?=` 短标签绕过危险内容扫描；
6. 上传 WebShell 并根据回显判断代码是否被解析、执行；
7. 在 Windows 环境下通过命令执行查找目录，最终读取 flag。

文中每一步都配有请求截图和回显说明，并对"为什么这样做"给出了分析。

## 涵盖知识点

- 如何通过"是否发出新请求"判断前端与后端检测；
- 后缀名黑名单、大小写绕过、MIME 类型与 GIF89a 魔术头；
- `<?=` 短标签与 `<?php` 标签的区别，以及后端危险内容扫描的触发逻辑；
- PHP 代码利用三步：**上传 → 解析 → 执行**；
- 根据页面回显与源码判断代码"未被解析 / 被解析但未执行 / 已执行"；
- Windows 下常用命令执行与文件读取方式。
